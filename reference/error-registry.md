# 오류 대장 — 다시 만들지 않을 실수

> 컨텍스트에 넣지 않는다. 사람이 보거나, 같은 실수의 원인을 조사할 때만 연다.
> 여기 있는 규칙은 이미 `kit/`의 지침과 스킬에 한 줄씩 들어가 있다.

실제로 일어난 일만 적는다. 새 실수가 나오면 두 가지를 한다.
1. 같은 형식으로 맨 아래에 추가한다(번호는 이어서).
2. 그 규칙을 `kit/`의 해당 파일에 한 줄로 넣는다. 모든 대화에서 지켜야 하면 `instructions.md`, 특정 작업에서만이면 해당 스킬이다.
출처 약어: **고등어** = 「어머니와 고등어」 확정 사항·가이드 / **나부코** = 나부코 배경 영상 Docs(지침서·1구간 수정안·N1~N5) / **Prompter** = The Prompter 씬 1 분석 / **HF** = Higgsfield 거래·프로젝트 기록 / **환경** = Claude 세션·리포·사이트 운영.
