# 핸드오프 — 컷 세션이 끝날 때 총괄에 넘기는 보고

> 컷 세션은 끝날 때(또는 대화가 길어져 새 세션으로 넘어갈 때) 이 블록을 출력한다.
> 사용자는 이 블록을 총괄 세션에 붙이거나 `log/handoffs/C##_[날짜].md`로 저장한다.

```text
받는 세션: 총괄
보낸 세션: C[##] · [날짜]
상태: [진행 중 / 컷 확정(사용자 픽스) / 보류]

[1] 확정된 것 (사용자가 픽스한 것만)
- 퍼스트 프레임: job [ID] · [모델·해상도] · 한계: [ ]
- 영상: job [ID] · [모델·해상도·길이] · 한계: [ ]
- 확정 프롬프트 위치: [cuts/C##.md §프롬프트 / 첨부]

[2] 이번 세션 생성 기록
- 이미지 [N]회 / 영상 [N]회 / 약 [N] 크레딧
- 버린 것: [job — 이유 한 줄] …

[3] 바뀐 결정 (사용자가 새로 정하거나 번복한 것)
- [결정 한 줄] — 근거: [사용자 말 / job]

[4] 새로 발견한 실패와 막는 문장
- [증상] → [원인] → [막는 문장]   (공통이면 오류 대장 E-번호 후보)

[5] 총괄에 올릴 것 (이 컷 범위 밖)
- [예: 장소 뷰 V6의 식탁 위치가 V2와 다름 / 이웃 C05 첫 프레임에 영향 — 봉지 상태 풀림]

[6] 다음에 할 일
- [다음 세션이 바로 시작할 수 있게 한두 줄]
```
