# 세션 시작 문구 (복사해서 새 대화 첫 메시지로)

프로젝트 지침과 지식 파일이 이미 들어 있으면 아래 문구만으로 충분하다. 같은 설명을 다시 하지 않는다.

---

## 총괄 세션

```text
이 대화는 「[작품명]」의 총괄 세션이다.
1) decisions.md → shot-list.md → asset-registry.md 순서로 읽고 현재 상태를 다섯 줄로 요약해.
2) 아래 핸드오프가 있으면 guide/02_session-system.md §5 순서로 처리하고 반영할 변경을 목록으로 보여 줘(반영은 내가 확인한 뒤).
3) 오늘 할 일: [ ]
생성은 하지 마. 컷 카드가 필요하면 templates/cut-card.md 형식으로 만들어.

[핸드오프 붙이는 자리]
```

## 컷 세션

```text
이 대화는 「[작품명]」의 컷 세션이다. 아래 컷 카드 한 장의 범위만 작업한다.
다른 컷이나 전체 시나리오는 읽지 마. 범위 밖 문제는 끝의 핸드오프에 적어.
먼저 카드에서 모호한 점과 실패 위험을 꼽고, 퍼스트 프레임 이미지 프롬프트부터 보여 줘(생성은 내가 지시할 때만).
끝낼 때는 templates/handoff.md 형식으로 보고해.

[컷 카드 붙이는 자리]
```

## 이어서 하는 컷 세션 (같은 컷, 새 대화)

```text
「[작품명]」 C[##] 컷 세션을 이어서 한다. 아래 컷 카드와 마지막 핸드오프만 기준으로 삼아.
핸드오프 [6] 다음에 할 일부터 시작해.

[컷 카드]
[마지막 핸드오프]
```

## 단발 작업 (작품 밖, 한 장·한 컷)

```text
guide/00 규칙을 따른다. 결과물: [ ]. 모델: [ ]. 해상도: 확인용 [1k/480p].
먼저 시작 전 질문(templates/decisions.md §0) 중 이 작업에 필요한 것만 한 번에 물어봐.
```
