이 리포는 「[작품명]」의 AI 이미지·영상 제작 기록이다. 답은 한국어로 한다.

## 항상 따르는 규칙

@guide/00_project-instructions.md

(위 줄은 Claude Code의 파일 불러오기다. 불러오기가 안 되는 환경이면 `guide/00_project-instructions.md`를 먼저 읽는다.)

## 이 리포의 정본

| 무엇 | 파일 | 누가 고치나 |
|---|---|---|
| 확정 사항 | `project/decisions.md` | 총괄 세션 |
| 에셋 대장 | `project/asset-registry.md` | 총괄 세션 |
| 컷 목록 | `project/shot-list.md` | 총괄 세션 |
| 컷 카드 | `project/cuts/C##.md` | 총괄이 발행, 컷 세션은 [프롬프트]·[시도] 칸만 |
| 핸드오프·시행착오 | `project/log/` | 누구나 추가만(수정·삭제 안 함) |
| 미디어 | Higgsfield 프로젝트 「[작품명]」 폴더 [구간/컷] | 생성은 반드시 이 폴더 안에서 |

- 세션 시작: 이 세션이 총괄인지 컷(C##)인지 첫 메시지로 확인한다. 컷 세션은 자기 컷 카드 외의 컷 파일을 읽지 않는다.
- `project/log/`는 원인 조사가 필요할 때만 읽는다.
- 파일을 고칠 때는 해당 줄만 고친다. 정본 문서를 통째로 다시 쓰지 않는다.
- 다른 세션이 고치는 중인 파일을 동시에 고치지 않는다. 겹치면 총괄이 순서를 정한다.
