# 에셋·폴더 대장 — 「[작품명]」

> 이 대장에 두는 것:
> - Higgsfield 저장 폴더
> - 인물·장소·소품·그림체 기준의 ID, 확정 이미지, 고정 설명문(글자 그대로 재사용), 알려진 한계
>
> 고정 설명문은 프롬프트에 **토씨 하나 바꾸지 않고** 붙인다. 바꿔야 하면 새 버전(v2)을 만들고 옛 것에는 폐기 표시를 한다.
> 확정 이미지의 정본은 Higgsfield 저장본이다. 아래 job ID로 직접 열어 확인한다.
