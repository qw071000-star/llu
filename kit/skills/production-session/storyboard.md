# 콘티 (storyboard) and canon from the folders

The 콘티 is where `decisions.md` §7 `콘티 위치` says (a site or a doc).
- **Reflect without asking:** an approved image goes into its cut on the 콘티, and status, a new cut, or a changed line are written there as soon as they happen. Report it as one line `콘티: 전 → 후` per change. On the 콘티 record only the account that made the result (`B`), no person's name.
- **New cut between two cuts:** take a number between them (`1-3.5` between `1-3` and `1-4`); never renumber existing cuts (`shared-account.md` 6).
- **Source of truth for approval:** the heart in the cut folder (`higgsfield-generation` §4). At session start and after an approval, reconcile the 콘티 and `shot-list.md` with it.
- **Reworking an approved cut:** 콘티 수정작업중 on, ` [승인]` off the folder name, canon status back to `진행`, all in the same turn.
