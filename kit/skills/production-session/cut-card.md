# 컷 카드 — 총괄 → 컷 세션

3천 자 이하로 쓴다. 넘으면 [11]의 옛 시도를 로그로 옮긴다. 다른 컷, 전체 시나리오, 시행착오는 넣지 않는다.
다른 컷 카드를 형식 예시로 열지 않는다. 이 틀을 쓴다.
고치는 사람: 총괄 [1] [2] [8] [9] · 컷 세션 [3]~[7] [10]~[12]. 사용자가 정하지 않은 값에는 `(제안값)`을 붙인다.

```text
받는 세션: [컷 번호 3-1]
카드 버전: v[N] · [날짜]

[1] 목표: [이 컷이 하는 일 한 줄] / 완료 조건: [ ]
[2] 저장 위치: 프로젝트 `[ ]` / 컷 폴더 `[ ]` / 승인 `[ ]` / 거절 `[ ]`
[3] 형식: 길이 [ ] · 비율 [ ] · 크롭 [ ] · 가림 구역 [ ] · 모델 [ ] · 소리 [ ]
[4] 카메라: 위치(물건 기준) [ ] · 높이 [ ] · 방향 [ ] · 고정/움직임 [종류·속도·양]
    렌즈: [시작 이미지의 mm] = 대각 화각 [ ]° (`video-prompt` §2 환산표) · 관찰 결과 [ ] · 심도·초점 [ ]
[5] 인물 (인물마다)
    시작(0:00): [위치(물건 기준) · 자세 · 하던 동작 · 손]
    끝(마지막 프레임): [위치 · 자세]
    동선: [경로 · 지나가지 않는 구역 · 걸음 속도]
    시선: [0:00–0:0a 대상 → 0:0a– 대상] · 반응하지 않을 사람: [ ]
    소품: [위치 · 상태 A → 상태 B · 어느 손(물건 기준)]
[6] 타이밍: [0:00–0:0a 주요 액션] / [대사 원문 · 횟수 · 구간] / 마지막 프레임: [ ]
    이음새: 앞 컷에서 이어받는 것 [ ] / 다음 컷 첫 프레임과 맞출 것 [ ]
[7] 참조: [ID · 역할 · 권한] (줄마다 하나)
    가져온 OK: [번호 종류 — 요소(블록)] (없으면 "없음")
[8] 고정 설명문: [에셋 대장 항목 이름만. 예: CH-001 WARDROBE · PR-001 · LC-001 LIGHT LOCK · LC-001-V1 화면 대응] (프롬프트를 쓸 때 대장에서 글자 그대로 복사한다)
[9] 이 컷에 적용되는 확정 사항: [decisions.md의 해당 줄만]
[10] 알려진 위험 → 막는 문장: [이 컷과, 가져온 OK에서 실제로 났던 실패]
[11] 이전 시도: [job — 승인/거절/보류 — 이유 한 줄]
[12] 확정 프롬프트: [OK 대장 카드 이름(3-1 영상)과 job. 전문은 그 카드에만 둔다]
```
