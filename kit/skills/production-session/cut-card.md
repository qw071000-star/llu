# 컷 카드 — 총괄 세션이 컷 세션에 넘기는 패킷

- 컷 세션은 이 카드와 지침만 보고 작업할 수 있어야 한다.
- 3천 자 안팎으로 쓴다. 다른 컷, 전체 시나리오, 옛 시행착오는 넣지 않는다.

```text
받는 세션: C[##]
카드 버전: v[N] · [날짜] · 발행: 총괄

[1] 목표
- 이 컷이 하는 일(한 줄): [ ]
- 완료 조건: [퍼스트 프레임 확정 + 480p 영상 확정 → 사용자 픽스 후 1080p]

[2] 저장 위치
- Higgsfield 프로젝트 [이름] `[project_id]` / 컷 폴더 `C[##]` `[folder_id]`
- 승인 폴더 `[folder_id]` / 거절 폴더 `[folder_id]`

[3] 형식
- 길이 [8초] · 생성 비율 [16:9] · 최종 크롭 [ ] · 가림 구역 [ ]
- 모델: 이미지 [모델·1k] / 영상 [모델·480p] / 소리 [대사 1줄 · 음악 없음]

[4] 카메라 (콘티 그대로)
- [고정 · 아이레벨 · 위치(물건 기준) · 방향 · 화각 63°]

[5] 첫 프레임 (0:00 상태)
- [인물별 위치(물건 기준)·자세·동작 도중·시선·손]
- [소품 위치·상태·소유]

[6] 행동 타임라인
- 0:00–0:03 [ ]
- 0:03–0:05.5 [ ] 대사: "[원문]" 한 번
- 0:05.5–0:08 [ ] / 마지막 프레임: [ ]

[7] 참조 (ID · 역할 · 권한)
- 장소 뷰 [LC-…] `[요소 ID]` · 기하·재질·빛 방향 · 구도는 통제하지 않음
- 인물 [CH-…] `[요소 ID]` · 얼굴·의상
- 소품 [PR-…] `[요소 ID]` · 모양·재질·상태 (크기는 시작 이미지)

[8] 고정 설명문 (에셋 대장에서 글자 그대로)
- [ ]

[9] 이 컷에 적용되는 확정 사항 (decisions.md에서 해당 줄만)
- [ ]

[10] 알려진 위험과 막는 문장
- [위험] → [막는 문장]

[11] 이전 시도 (결과만)
- [job ID — 상태(승인/거절/보류) — 이유 한 줄]

[12] 확정 프롬프트
- 퍼스트 프레임: job [ID] / 영상: job [ID]
- 전문은 여기 붙이지 않는다. 고칠 때 get_project_asset_prompt로 그 job에서 가져온다.
```
