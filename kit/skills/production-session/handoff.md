# 핸드오프 — 컷 세션이 끝날 때 총괄에 넘기는 보고

- 컷 세션이 끝날 때, 또는 새 대화로 넘어갈 때 출력한다. 40줄 이하로 쓴다.
- 읽는 사람은 다음 세션의 Claude다. 경위는 쓰지 않고, 결과와 다음 할 일만 쓴다.

```text
받는 세션: 총괄
보낸 세션: C[##] · [날짜]
컷 상태: [진행 / 검토 / 승인 / 보류]

[1] 확정된 것 (사용자가 승인한 것만)
- 퍼스트 프레임: job [ID] · [모델·해상도] · 한계: [ ]
- 영상: job [ID] · [모델·해상도·길이] · 한계: [ ]

[2] 이번 세션 생성
- 이미지 [N]회 / 영상 [N]회 / 약 [N] 크레딧
- 거절: [job — 이유 한 줄] …   (Higgsfield `거절` 폴더로 옮김: 예/아니오)

[3] 바뀐 결정
- [결정 한 줄] — 근거: [사용자 말 / job]

[4] 새로 발견한 실패와 막는 문장
- [증상] → [원인] → [막는 문장]

[5] 총괄에 올릴 것 (이 컷 범위 밖)
- [ ]

[6] 다음에 할 일
- [다음 세션이 바로 시작할 한두 줄]
```
