# 영상 프롬프트 — 공통

## 단계 파일 — 하나만 연다

- `live-action.md`: 인물·소품·대사가 있는 실사 컷 (15블록)
- `background.md`: 인물 연기가 없는 배경·풍경·그림체 (4문단)
- `fixes.md`: 결과가 틀려서 고친다. 그 증상 줄만 본다. 형식 파일과 빈 틀은 다시 읽지 않는다
- `rerender.md`: 확정한 저해상도 테이크를 고해상도로

## 0. 쓰기 전 정보 점검

실사 컷(15블록)이면 아래 표를 채운다. 표의 각 줄은 15블록의 한 블록에 들어간다.

| 구분 | 필요한 정보 | 들어가는 블록 |
|---|---|---|
| 장면 | 이 클립에서 일어나는 일(2~4문장), 시대·장소·시간대 | `SCENE_CONTEXT` |
| 형식 | 길이, 화면비, 모델, 소리(대사·효과음·음악 여부), 저장 폴더 | `FORMAT_MODE`, `AUDIO` |
| 룩 | 매체·질감·색조(`decisions.md`의 룩 기준) | `STYLE` |
| 인물 에셋 | 인물마다 요소 ID, 의상·헤어 상태 버전, 고정 설명문, 대사가 있으면 목소리 문장 | `ACTIVE_REFERENCES`, `AUDIO` |
| 장소 | 장소 뷰 요소 ID, 화면 좌·중·우·전경의 랜드마크, 시간대 | `ACTIVE_REFERENCES`, `LOCATION_MAP` |
| 소품 | 요소 ID, 시작 상태 → 끝 상태, 누가 어느 손(물건 기준)에 드는가, 크기 | `ACTIVE_REFERENCES`, `PHYSICS` |
| 시작 이미지 | 퍼스트 프레임 job (없으면 퍼스트 프레임부터 만들자고 묻는다), 끝 프레임을 쓸지 | `ACTIVE_REFERENCES` |
| 카메라 | 위치(물건 기준), 높이, 방향, 고정 또는 움직임 한 가지(종류·속도·양) | `CAMERA` |
| 렌즈 | 대각 화각(도), 관찰 결과 3개, 심도·초점 이동 | `OPTICS` |
| 인물 위치 | 인물마다 시작 위치(0:00, 물건 기준)·자세·하던 동작, 끝 위치(마지막 프레임) | `FIRST_FRAME_AND_SPATIAL_BLOCKING`, `ACTION_TIMING` |
| 동선 | 이동 경로, 지나가지 않는 구역, 걸음 속도 | `LOCATION_MAP`, `ACTION_TIMING` |
| 시선 | 인물마다 무엇을 보는지, 언제 시선이 바뀌는지, 반응하지 않을 사람 | `ACTION_TIMING`, `CHARACTER_ACTING` |
| 타이밍 | 주요 액션의 구간(`0:00–0:03`), 대사 원문·횟수·위치, 소품 상태가 바뀌는 시점 | `ACTION_TIMING`, `AUDIO` |
| 연기 | 인물마다 목표, 감정 범위의 양 끝 | `CHARACTER_ACTING` |
| 빛 | 지배 광원과 방향 | `LIGHTING` |
| 이음새 | 앞 컷에서 이어받는 상태, 다음 컷 첫 프레임과 맞출 것 | `PRE_SHOT_CONTINUITY` |
| 금지 | 이 컷의 거절 이유·[10], 가져온 OK의 위험(`production-session` → `ok-reuse.md` §3), 에셋 대장의 인물 "알려진 실패" | `REQUIRED_AND_FORBIDDEN_CONSTRAINTS` |

배경·풍경 영상(4문단)이면 다음 표만 채운다.

| 필요한 정보 | 들어가는 문단 |
|---|---|
| 시작 이미지 job, 모델, 길이, 화면비, 저장 폴더 | 설정 |
| 카메라 움직임: 종류·방향·양(화면 %)·속도 | `Camera` |
| 움직일 것: 이미지에 이미 있는 것마다 방향·속도 | `Motion` |
| 매체, 유지할 형태, 빛 방향 | `Keep` |
| 소리(끌 수 있는지) | `Silent` |

**이웃 컷의 끝 상태**는 컷 목록의 이음새·연속성 표에서 가져온다.

**묻는 법은 지침 4번이다.** 영상에서 더할 것:
- `decisions.md` 기본값을 쓴 칸은 묻지 않고 한 줄로 보인다: `기본값으로 씀: 8초 · 고정 카메라 · 480p · 효과음만`.
- 질문이 10개를 넘으면 한 메시지 안에서 소제목(카메라 / 인물 / 타이밍)으로 묶는다. 여러 턴으로 나누지 않는다.

예: `[카메라] 1. 렌즈: 제안 — 대각 약 63° (이유: 세 사람이 한 화면에 다 들어옴)` · `[인물] 2. [인물 A] 시선: 제안 — 0:00–0:03 [대상], 이후 [대상]` · `[타이밍] 3. 주요 액션: 제안 — 0:03에 [동작] (이유: 사건 3개 이하)`

**답은 컷 카드 [4]~[6]에 적는다.** 다시 시도하거나 다음 컷을 쓸 때도 같은 값을 쓴다. 값이 바뀌면 컷 카드를 먼저 고친다.

**일관성 점검 (쓰고 나서)**
- 이 컷의 시작 상태가 앞 컷의 끝 상태와 같은가(위치, 소품 상태, 빛)
- 장소 뷰의 화면 대응 줄·LIGHT LOCK(에셋 대장)과 좌우 기준, 광원 방향이 맞는가

## 1. 일곱 원칙

1. **사건 수가 성패를 가른다.** 글자 수보다 중요하다. 안 풀리면 컷·동작·요소·대사를 줄인다.
2. **전환이 아니라 상태를 쓴다.** 시작 상태와 끝 상태를 고정한다. 사이가 길면 생성을 나눈다.
3. **첫 프레임은 영상의 0:00이다.** 첫 프레임 문단은 시작 이미지와 같아야 한다.
4. **카메라 동작은 한 생성에 하나.**
5. **좌우는 화면 기준이다.** `LEFT and RIGHT are SCREEN directions.`를 쓰고, 자리는 화면 속 물건으로 가리킨다.
6. **참조마다 통제 범위를 적는다.** 장소 참조는 구도를 통제하지 않고, 인물 참조는 얼굴·의상만 통제한다.
7. **위험마다 막는 문장 한 줄.** 실제로 났던 실패(거절 이유, 컷 카드 [10], 가져온 OK의 위험, 에셋 대장의 인물 "알려진 실패")만 Forbidden에 범위 태그와 함께 둔다. 예상 위험은 Required나 해당 블록 문장으로 막는다. 같은 증상을 막는 문장이 이미 있으면 더하지 않고 그 문장을 바꾼다.

## 2. 샷 설계

| 정할 것 | 기준 |
|---|---|
| 길이 | 정본의 컷 길이를 따른다. 정본에 없으면 대사·동작 실사 5~10초, 배경 10~15초. 15초를 넘으면 나눈다 |
| 렌즈 환산 | 대각 화각은 풀프레임 기준으로 환산한다: 24mm 84° · 28mm 75° · 35mm 63° · 50mm 47° · 75mm 32° · 85mm 29° · 100mm 24° · 135mm 18°. 컷 카드와 시작 이미지가 다르면 시작 이미지가 이긴다(알리고 진행). 사용자 말과 시작 이미지가 다르면 묻는다 |
| 이어 붙이기 | 뒤 생성은 앞 생성의 지정 프레임을 `start_image`로 받는다 |
| 장소 | 한 생성에 한 장소. 새 장소는 먼저 이미지로 확정한다 |
| 사건 수 | 한 생성에 1~3개. 인물마다 할 일 하나. 대사 한 줄에 2~4초 |
| 끝 프레임 | 꼭 도착해야 할 구도가 있을 때만 쓴다 |

## 3. 모델 메모

| 모델 | 메모 |
|---|---|
| Seedance 2.5 | 참조는 `<<<요소ID>>>`로 부르고, 붙인 요소와 정확히 맞춘다. 소리가 기본으로 켜져 있어 AUDIO 블록이 필요하다. 음성 참조는 붙인 순서대로 audio_1, audio_2다. Extend는 화면비가 바뀔 수 있다 |
| Kling 4.0 | 이미지에 있는 것을 다시 쓰지 않고 움직임과 유지할 것만 쓴다. 카메라는 별도 문단으로 쓰고, 끝 상태는 쓰지 않는다 |

## 4. 보내기 전 점검 (검사 스크립트가 잡지 못하는 것)

- [ ] 첫 프레임 문단이 시작 이미지(0:00)와 같은가
- [ ] 참조마다 권한을 적었는가. 장소 참조에 구도 권한을 주지 않았는가
- [ ] 렌즈를 화각(도) + 관찰 결과 3개로 썼는가
- [ ] 횟수(한 번 / 계속)와 범위(첫 프레임 / 구간 / 전체)를 지켰는가
- [ ] 이 샷에 없는 인물이 남아 있지 않은가
- [ ] 위험마다 막는 문장이 §1의 7번대로 있는가
- [ ] 보이기 전에 검사 스크립트를 돌렸는가. 프롬프트를 파일로 저장하고 `higgsfield-generation` 스킬 폴더의 `check_prompt.py`를 `python3 check_prompt.py --kind video 파일 --refs 붙일요소수 --seconds 길이 [--must-include 고정문장파일]`로 돌린다(그 스킬을 열 필요는 없다). FAIL은 고친다. WARN은 고치거나 남길 이유를 검사 출력의 숫자와 함께 한 줄 적는다. 코드 실행이 안 되면 그렇다고 적는다
