# 증상별 수정 — 결과가 틀렸을 때 해당 줄만 찾아 쓴다

효과를 본 수정만 적는다. 같은 실패가 2회를 넘으면 문장을 더하지 말고 샷을 바꾼다(SKILL.md §2).

| 증상 | 수정 |
|---|---|
| 빈 방으로 시작해 인물이 걸어 들어온다 | 첫 프레임부터 정위치, 동작 도중. 등장은 "이미 걷는 중, 문은 뒤에서 닫히는 중"으로 |
| 문이 저절로 열리고 닫혀 어색하다 | 그 사건을 빼고 문은 숏 내내 닫힌 상태로 둔다 |
| 인물이 휙 돈다 | 부위 순서와 초를 쓴다: `eyes → head → shoulders, about 1.5 s; snapping = failed take` |
| 말하지 않을 인물의 입이 움직인다 | "말하려다 만다"를 빼고 "말하려는 시도 자체가 없다(입술 벌림·입 모양 없음)"로 쓴다 |
| 고개를 돌렸다가 되돌린다 | `From then until the end his eyes and head stay on her. Turning back = forbidden` |
| 다른 인물이 반응해 버린다 | 그 인물의 시선·머리·손을 끝까지 고정: `does not react in any way, never looks at him` |
| 소품이 다른 손으로 가거나, 커지거나, 다른 탁자로 간다 | 소품 요소를 붙이고 손(물건 기준), 내려놓지 않음, 크기는 시작 이미지와 같음을 적는다. 같은 종류 물건이 둘이면 이름으로 구분한다 |
| 참조 사진의 얼굴·색·조명이 섞인다 | 그 사진을 붙이지 않는다. 그 구도로 만든 빈 장소 이미지를 장소 참조로 쓴다 |
| 거울·유리에 엉뚱한 것이 비친다 | 비치는 것과 비치지 않는 것을 함께 적는다 |
| 해가 납작한 원반으로 뜬다 | 모양이 아니라 윤곽 없이 번지는 빛으로 쓴다. 원반·테두리를 금지하고, 아랫부분은 지평선 안개에 둔다 |
| 새 떼가 점으로 뭉개진다 | "카메라와 같은 속도로 같은 크기·위치 유지". 멀어지며 작아진다고 쓰지 않는다. 안 되면 오버레이 소재로 따로 만든다 |
| 카메라가 지정 지점이 아니라 화면 가운데로 직진한다 | "피사체를 따라가는 추적 촬영"으로 바꾼다. 확대량은 원하는 양의 절반으로 쓴다(2배 요청에 3.5배가 나왔다) |
| 연기가 크거나 무표정하다 | 감정 범위의 양 끝을 failed take로 닫는다 |
| 배경 인물이 얼어붙거나 한꺼번에 움직인다 | 인원 수를 적고 각자 다른 일 하나를 준다. 이름 없는 인원은 얼굴 없는 실루엣으로 |
| 같은 프롬프트를 4번 돌려도 안 된다 | 개념을 단순하게 하거나 샷을 나눈다 |
