# 소품

## 규칙

- **상태·손·크기가 바뀌는 소품은 독립 에셋으로 만든다.** 무배경 회색 스튜디오에 소품만 두고, 사용감을 준다.
- **크기는 소품 에셋이 아니라 장면에서 정한다.**
  - 흰 배경에 선 봉지를 참조로 쓰자 봉지가 인물 상체만큼 커졌다.
  - 장면 프레임에서 잘라 만든 요소로 바꾸자 풀렸다.
  - 크기는 cm와 신체 기준(무릎 위, 허벅지 폭)을 함께 적는다.
- **물성은 무게로 쓴다.** 예: "두 마리 무게로 아래가 처진다. 공기로 부풀지 않는다. 각이 서지 않는다."
- **상태 머신으로 관리한다.** 예: 묶임 → 풀림 → 들고 감. 컷 사이의 상태는 `shot-list.md` 연속성 표에 둔다.
- **기록:** 에셋 대장에 요소 ID, 출처(장면에서 잘라 만듦 / 스튜디오 생성), 크기, 물성, 상태 머신을 적는다.

## 틀 — 소품 독립 에셋

```text
Photorealistic product-reference photograph of [prop: material, wear, size cue], isolated on a plain
seamless light grey studio background, nothing else in frame — no scene, no room, no other objects,
no hands, no people. [Use marks: small scratches from daily use.] Soft even studio lighting from the
front-top, minimal shadow. Sharp focus throughout. Avoid: [wrong materials], brand logos, text, watermarks.
```
