# 새 작품 시작

목표: 사용자가 질문 한 번에 답하면 작업을 시작할 수 있는 상태가 된다. 질문을 여러 번에 나눠 하지 않는다.

## 1. 한 번에 묻는다

아래 표를 그대로 보이고 "바꿀 것만 답해 주세요. 나머지는 기본값으로 합니다."라고 쓴다.
사용자가 준 시나리오나 콘티가 있으면 먼저 읽고, 거기서 알 수 있는 칸은 채워서 보인다.

| # | 질문 | 기본값 |
|---|---|---|
| 1 | 최종 화면 크기·비율, 가려지는 구역(자막·출연자·로고) | 16:9, 가림 없음 |
| 2 | 전체 길이, 구간·컷 수, 컷당 길이 | 컷당 8초 |
| 3 | 실사인가 그림체인가, 기준이 될 이미지 | — (필수) |

| 5 | 확인용·확정 해상도, 소리 | 확인 1k·480p, 확정 2k·1080p, 소리 끔(대사 컷만 켬) |

## 2. 답을 받으면 정본 초안을 만든다

- `decisions.md`: §1~§9에 답을 한 줄씩 적는다. 날짜와 "사용자 답" 또는 "기본값"을 붙인다. 모르는 것은 미결 표에 둔다.
- `shot-list.md`: 시나리오나 콘티가 있으면 컷을 나눠 한 줄씩 적는다(상태 `대기`). 없으면 빈 표로 둔다.
- `asset-registry.md`: 등장할 인물·장소·소품에 ID만 매긴다(CH-001, LC-001, PR-001). 내용은 에셋을 확정할 때 채운다.

## 3. Higgsfield 프로젝트와 폴더

1. 기존 프로젝트를 쓴다면 `list_projects`로 찾아 ID를 확인한다.
2. 새로 만든다면 사용자의 승인을 받은 뒤 만든다.
3. 폴더 구성안을 보인다(`higgsfield-generation` §2의 구성).
   - 지금 만드는 것: `00 에셋`(인물·장소·소품·그림체 하위 폴더 포함)과 `99 시험·보관`.
   - 컷 폴더는 컷 카드를 발행할 때 만든다.
4. 승인을 받으면 `create_folder`로 만든다.
   - 사용자가 직접 만들겠다고 하면 정확한 이름을 알려 준다.
5. 받은 ID를 `asset-registry.md` 폴더 표에 적는다.

## 4. 넘겨줄 것

- **Claude 앱:** 정본 세 개의 전문을 파일별 코드블록으로 준다. 사용자는 이것을 프로젝트 지식에 올린다.
  - 함께 줄 것: 지침 칸 맨 위 "이 프로젝트" 두 줄(작품명, Higgsfield 프로젝트 ID).
- **Claude Code:** `project/` 아래에 저장한다.

## 5. 다음 순서를 안내한다 (한 줄씩)

1. 그림체나 룩 기준 이미지를 확정한다(그림체 작품만).
2. 인물 + 의상 시트를 만든다.
3. 장소 마스터를 만든다.
4. 소품 에셋을 만든다.
5. 컷 카드를 발행하고, 컷 세션을 연다.
