# 인물 연기

영상 프롬프트 15블록의 `CHARACTER_ACTING`(9번)을 채울 때 읽는다. 원본은 「어머니와 고등어」의 `acting-guide.md`다(인물별 마스터 프로필 포함). 여기에는 어느 작품에나 쓰는 부분만 남겼다.

---

## 0. 공리

**연기는 감정의 전시가 아니라 압력 아래의 행동이다.** 인물이 무언가를 원하고, 무언가가 막고, 그것을 얻으려 행동한다. 감정은 부산물이지 쓰는 대상이 아니다.

| 쓰지 않는다 | 쓴다 |
|---|---|
| "화가 난다", "슬프게" | 상대를 향한 동사: "돈을 돌려받게 만든다" |
| 자기 대사 차례를 기다리는 빈 얼굴 | 상대 말이 끝나기 전에 시작되는 반응 |
| 몸이 대사를 삽화처럼 따라감 | 손이 진짜 일을 하고, 때로 말과 어긋남 |
| 얼굴이 연기함(눈썹·찡그림) | 얼굴이 생각함 — 말보다 눈에 먼저 읽힘 |

---

## 1. 장면마다 정할 다섯 가지

1. **목표**: 지금, 이 상대에게서 원하는 것(동사).
2. **장애와 대가**: 무엇이 막는가, 실패하면 무엇을 잃는가.
3. **전술**: 압박·구슬림·시간 끌기 등. 실패하면 바꾼다.
4. **비트**: 한 장면에 2~4번 바뀐다. 바뀔 때 행동으로 보인다(사이·자세·속도·시선).
5. **서브텍스트**: 연기하지 않는다. 거짓 텍스트를 말하며 진짜 목표를 추구하면 저절로 샌다.

## 2. 몸

- **비즈니스(손이 하는 일)**를 준다: 생선을 손질하며, 봉지를 뒤지며, 양말을 벗으며 말한다. 가짜 연극성이 죽고 리듬이 생긴다.
- **중단된 행동이 가장 강한 강세다.** 하던 일을 멈추는 순간이 사건이 된다. 멈출 때 "놀라지 않는다. 그냥 멈춘다"를 붙인다.
- **거리 변화 = 비트 변화.** 0.5m 친밀 / 1.2m 신뢰 / 3.5m 경계 / 그 이상 소외.
- **지위는 몸에 있다.** 높음: 움직이지 않는 머리, 느린 동작, 답하기 전의 사이. 낮음: 부산함, 자기 접촉, 끊기는 말.
- **걸음에 이름을 붙인다**: `"end-of-day walk" — small steps, almost no arm swing`. 이름이 생체역학을 고정한다.

## 3. 눈 — AI 연기의 1번 실패 지점

```text
continuous naturalistic eye life: micro-saccades and gaze targeting, the gaze drifting and settling
rather than locking, realistic blink rate tied to state, live wet catchlights, the eyes reaching
the target a beat before the head turns
```

- 눈이 고개보다 반 박자 먼저 대상에 닿는다.
- 인물 시트에는 눈의 **물리**(습기·캐치라이트·초점 거리)만, 눈의 **성격**은 컷 프롬프트에.

## 4. 상태를 쓴다

영상 모델은 전환에 실패하고 상태에 성공한다. "가방에 손을 넣어 꺼내 들고 던질 준비를 한다"는 무너지고, "던지는 중, 팔이 뻗은 상태"는 성립한다. 연속 과정은 비트마다 상태를 이어 붙인다(15블록 `ACTION_TIMING`의 구간과 맞춘다).

## 5. 마스터 프로필 — 반복 등장하는 인물마다 하나

150~220단어 영어 한 문단, 관찰 가능한 것만. 에셋 대장에 두고 장면마다 **다시 쓴다(붙여넣지 않는다)**.

```text
Character acting as [NAME]. [나이·체격·자세 — 몸이 전기를 말한다]. [심리적 엔진 한 절].
Vocal profile: [음역·억양·속도·압력 아래 변화]. Key physical habits and tics: [틱 + 발동 조건;
스트레스 틱 + 조건; 감추는 행동; 가면과 깨지는 조건]. Eye life: [§3]. Walking style: ["이름" + 풀이].
However, when [방아쇠], [변형]. [부드러워지는 대상 하나].
```

- 모든 틱에 방아쇠를 붙인다(`[틱] + [언제/왜]`). 방아쇠 없는 틱은 장식이다.
- 의상·카메라·색은 넣지 않는다(프로필은 어떤 의상에도 살아남아야 한다).
- 장면 적응: 프레임에 있는 인물만 / 정체성·목소리·시그니처 틱·눈은 유지 / 그 장면의 자세·행동·비트로 다시 표현 / 불가능한 행동은 지우지 말고 배출구를 바꾼다(서성이는 사람이 앉아 있으면 손목 튕김으로).

## 6. 목소리는 고정

인물마다 Voice 문장 하나를 만들고 대사가 있을 때 오디오 쪽에 **그대로** 붙인다. 장면마다 바꾸지 않는다.

```text
"A [나이]-year-old [출신/억양]. [음색·음역]; [속도·전달]; [압력 아래 변화]."
```

## 7. 작품의 레지스터를 먼저 정한다

작품마다 "쓰는 연기 / 쓰지 않는 연기" 표를 `decisions.md`에 둔다. 예(담담한 가족 회상극): 정지·중단된 비즈니스·거리 변화·음식을 밀어주기·1초의 지위 파열을 쓰고, 울음·고함·감정 설명·클로즈업의 큰 표정은 쓰지 않는다. **숏이 타이트할수록 움직임을 줄인다.**

## 8. 같은 모델에서 효과가 확인된 문장 (Seedance 2.5, The Prompter 66개)

| 문제 | 문장 |
|---|---|
| 감정이 넘치거나 꺼짐 | 허용 범위를 두 상태 사이로, 양 끝을 실패로: "between weariness and wariness; hostility = failed take, warmth = failed take" |
| 몸이 휙 돈다 | 부위 순서와 초: "head → shoulders → feet over three seconds; turning within one second = failed take" |
| 말하지 않을 인물의 입이 움직임 | "no attempt to speak at all — no parted lips, no mouthing". "말하려다 삼킨다"는 입술이 아니라 숨·삼킴·손으로 쓴다 |
| 멈춤이 깜짝 놀람으로 읽힘 | "she does not startle; she simply stops". 이상한 것을 볼 때 "the action carries through and only the eyes stay on it" |
| 배경 인물이 얼거나 한꺼번에 움직임 | 인원 수 + 각자 다른 일 하나 + 이름 없는 인원은 얼굴 없는 실루엣 |
| 반응이 너무 크거나 없음 | "If the stiffening is strong or he sighs, it is a failed take; if there is no reaction at all, it is also a failed take." |

## 9. 나쁜 연기 → 고치는 법 (압축)

| 증상 | 수정 |
|---|---|
| 감정을 얼굴로 묘사 | 얼굴에서 과업을 빼고 목표와 손의 일을 준다 |
| 첫 초부터 결말을 연기 | 인물이 **지금** 아는 것만 쓴다 |
| 상대가 말하는 동안 빈 얼굴 | 반응이 상대 말 중간에 시작되게 |
| 한 톤으로 끝까지 | 비트마다 새 전술 동사 |
| 동시에 똑같이 반응하는 군중 | 파도처럼 어긋나게, 세기를 다르게 |
| 죽은 사이 | 평가나 비즈니스로 채우거나 자른다 |
| 강한 사건 뒤 즉시 회복 | 상태에 관성 — 흔적이 다음 비트로 |
| 클로즈업에서 큰 표정 | 눈과 생각만 |
| 죽은 눈 | §3 블록 전부 |

## 10. 보내기 전 점검

- [ ] 프레임 안 모든 인물에게 상대를 향한 동사의 목표가 있는가
- [ ] 비트 변화가 행동으로 보이는가
- [ ] 모든 인물에게 손의 일이 있는가
- [ ] 눈의 삶을 적었는가
- [ ] 감정 범위의 양 끝을 실패로 닫았는가
- [ ] 도는 동작은 부위 순서와 초로, 말하지 않는 입은 잠갔는가
- [ ] 상태를 썼는가(전환 아님). 연기 블록에 의상·카메라·색이 없는가
- [ ] 작품 레지스터를 넘지 않는가
