# 붙여넣기 — 그대로 복사해서 쓰는 프롬프트

파일을 열어 전체를 복사해 붙여 넣는다. `[ ]` 안만 바꾼다.

| 파일 | 언제 | 어디에 |
|---|---|---|
| `1-설치-ClaudeCode.txt` | 새 작품 폴더에 키트를 넣거나 새 버전으로 바꿀 때 | 작품 폴더에서 연 Claude Code |
| `2-설치확인-Claude앱.txt` | Claude 앱에 스킬 zip과 지침을 넣은 뒤 | 그 프로젝트의 새 대화 |
| `3-총괄-시작.txt` | 하루 시작 | 새 대화 |
| `4-씬-시작.txt` | 한 장면을 컷으로 나눌 때 | 새 대화 |
| `5-컷-시작.txt` | 컷 하나를 만들 때 | 새 대화 (컷마다 하나) |
| `6-컷-끝내기.txt` | 컷 대화를 끝낼 때 | 그 컷 대화 |
| `7-총괄-핸드오프반영.txt` | 컷 몇 개가 끝났을 때 | 총괄 대화 |
