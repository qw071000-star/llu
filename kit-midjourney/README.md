# 미드저니 전용 키트

Midjourney로 인물·장소·소품·스틸 컷(과 짧은 영상)을 만들 때 Claude를 같이 쓰는 키트입니다. Higgsfield 키트(`kit/`)와 **완전히 별개**이고, 파일을 서로 쓰지 않습니다. **이 폴더만 받으면 다른 프로젝트에서 그대로 적용할 수 있습니다**(리포의 다른 폴더가 필요 없습니다).

## 받는 법

- 가장 쉬운 방법: 리포 루트의 [`kit-midjourney.zip`](../kit-midjourney.zip)을 받아 압축을 풉니다(이 폴더 전체가 들어 있습니다).
- 리포를 통째로 받았다면 이 `kit-midjourney/` 폴더만 복사하면 됩니다.
- 실제로 올리는 파일은 `dist/`의 zip 5개와 `project-instructions.md` 하나뿐입니다.

## 먼저 알아 둘 것

- **미드저니는 Claude에 연결되지 않습니다.** Claude가 프롬프트를 쓰고, 사람이 미드저니에서 직접 실행해 결과(이미지나 링크)를 대화에 붙입니다. Claude는 이미지를 만들었다고 말하지 않고, 붙인 결과만 보고 판정합니다.
- **파라미터는 버전마다 다릅니다.** 키트는 `--oref`, `--sref`, `--ow`, `--stylize` 등을 외부 안내글로 확인했습니다. 공식 문서로는 확인하지 못해서, 결과가 파라미터를 무시하면 쓰는 버전의 현재 문서로 확인하세요. 영상 기능도 같습니다(생성으로 미검증).
- 정본 관리(확정 사항, 에셋 대장, 컷 목록, OK 대장, 컷 카드, 핸드오프)와 공용 계정 규칙은 Higgsfield 키트와 같은 방식입니다.

## 구성

```
kit-midjourney/
  instructions.md        항상 지키는 규칙 10개
  context/               할 일 목록(tasks.md), 꼭 물을 것(must-ask.md)
  project-files/         정본 틀 4개(확정 사항, 에셋 대장, 컷 목록, OK 대장)
  skills/                스킬 5개
    mj-setup             새 작품 시작: 질문 12개 → 정본
    mj-image             인물·장소·소품·그림체·스틸 컷 프롬프트
    mj-video             이미지 → 짧은 영상(미검증)
    mj-production        총괄·컷 세션, 컷 카드, 핸드오프, OK 기록, 공용 계정
    mj-shots             장면을 컷으로 나누기
  dist/                  업로드할 zip 5개 + project-instructions.md
  pack-skills.sh         skills/와 지침을 고친 뒤 dist/와 kit-midjourney.zip을 다시 만든다
  tests/run_tests.py     자동 점검(Higgsfield 전용 말이 섞이지 않았는지, 참조·zip이 맞는지)
  tests/sim/             Claude 앱을 흉내 낸 모의 시험(claude CLI 필요, 이미지는 만들지 않음)
```

## 설치 (claude.ai, 10분)

1. **스킬 올리기:** 설정에서 코드 실행을 켜고, 스킬 메뉴의 "Upload a skill"로 `dist/`의 zip 5개를 하나씩 올립니다(압축은 풀지 않습니다). 스킬은 계정마다 올립니다.
2. **프로젝트 만들기:** 새 프로젝트를 만들고 **지침 칸**에 `dist/project-instructions.md`를 통째로 붙입니다.
3. **"This project" 칸 채우기:** 맨 위의 작품명, Midjourney 버전(V7 등), Omni Reference 유무, 정본 위치(Docs 링크). 모르면 비워 두고 4번에서 채웁니다.
4. **새 대화에서 `새 작품 시작하자`** 라고 합니다. 질문 12개에 답하면 정본 초안이 만들어집니다. Claude Docs 도구가 있으면 정본 문서를 만들어 링크를 알려 주니, 그 링크를 지침 칸에 적습니다. 없으면 정본 4개를 프로젝트 지식에 올립니다.
5. Higgsfield 키트와 같은 계정에 올려도 이름이 달라서(`mj-…`) 서로 섞이지 않습니다. 다만 한 프로젝트에는 한 키트의 지침만 붙이세요.

## 작업 흐름

| 하고 싶은 것 | 이렇게 말한다 | 누가 무엇을 |
|---|---|---|
| 인물 | `인물 만들어. 20대 초반 히스패닉 남성, …` | Claude가 질문 → 클로즈업 프롬프트 → 사용자가 미드저니에서 실행 → 마음에 드는 1장을 붙이고 `됐어` → 정면·뒷모습은 그 이미지를 `--oref`로 |
| 장소 | `정류장 만들어` · `반대 방향도` | 마스터 뷰 먼저, 새 시점은 마스터를 이미지 프롬프트로 |
| 소품 | `왕진 가방 만들어` | |
| 스틸 컷 | `3-4 이미지 만들어` | 장소 → 인물 두 단계를 권함(한 번에 합치면 실패하기 쉬움) |
| 영상 | `3-4 영상으로` | 승인된 스틸을 시작 이미지로, 움직임 한 가지(`mj-video`) |
| 판정 | 이미지를 붙이고 `됐어` / `OK` / `거절` | 항목별로 맞음·틀림, 사용자가 승인 |
| 다른 컷처럼 | `3-1처럼 3-2 만들어` | OK 카드에서 프롬프트를 가져옴 |

세션 시작 말은 정해져 있지 않습니다. 컷 번호만(`3-2`) 말해도 Claude가 카드와 핸드오프를 보고 이어 갑니다. 총괄은 `총괄 세션이야. 오늘 뭐 하면 돼?`, 씬은 `3장면 컷 나눠 줘`로 시작하면 됩니다. 공용 계정이면 첫 말에 이름을 붙입니다(`나는 지수. 3-2 이어서`).

## 이미지 저장

미드저니에는 폴더 도구가 없으니 사용자가 직접 만듭니다: `00 에셋/인물·장소·소품·그림체`, `99 시험·보관`, 컷마다 `3-1 [대기]/승인·거절`. 파일 이름은 `char_<인물>_<상태>_v1`처럼 에셋 대장의 이름 규칙을 따르고, 링크는 정본에 적습니다.

## 고친 뒤

이 폴더 안에서:

```bash
bash pack-skills.sh
python3 tests/run_tests.py
```

`pack-skills.sh`가 `dist/`의 zip과 한 단계 위의 `kit-midjourney.zip`을 다시 만듭니다. 고친 뒤에는 바뀐 zip을 계정에 다시 올리고 지침 칸도 새 `project-instructions.md`로 바꿔 붙여야 합니다.
