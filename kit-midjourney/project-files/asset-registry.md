# 에셋 대장 — 「[작품명]」

> 고정 설명문(`MJ 문장`, 40단어 이하)을 바꿔야 하면 새 버전(v2)을 만들고, 옛 것은 폐기 목록으로 옮긴다.
> 확정 이미지는 링크로 연다. 확정 에셋을 만든 프롬프트와 설정은 OK 대장(`ok-cuts.md`)의 에셋 ID 카드에 있다.
> 이미지는 사용자가 요소 이름으로 저장한다(`00 에셋/인물·장소·소품·그림체`, 시험·폐기본은 `99 시험·보관`).
