## 키트 결함
1. 에셋 대장 LC-001의 `Nothing else`(사람 금지 포함)와 OK 대장 V1 카드의 `Nothing else`(현대 물건 금지 포함)가 서로 다름. 편집 프롬프트에 어느 쪽을 쓸지 규칙이 없음. 제안: 대장 쪽을 정본으로 못 박고 OK 카드의 확장 문장은 `Except`나 별도 줄로 분리.
2. `location-edit.md`는 "확정되면 그 STATE 뷰의 LIGHT LOCK을 적는다"만 있고, 켠 불의 화면 쪽 LIGHT LOCK을 질문 단계에서 제안하라는 문구가 없음. 제안: "빛을 바꾸는 편집은 질문 단계에서 새 LIGHT LOCK 제안문(화면 쪽 + 물건)을 보인다".

총평: 두 변경 분리와 질문 우선은 키트대로, 새 뷰 LIGHT LOCK 제안이 1턴에 없었고 `Nothing else`가 정본 두 곳 불일치로 흔들림.
