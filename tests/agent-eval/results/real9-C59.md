# real9-C59 다른 작업 셋을 한 번에 (1턴) — PASS 0 / 부분 1 / FAIL 0 (새 체인)

| 턴 | 판정 | 근거 |
|---|---|---|
| 1 | 부분 | 1-1·3-2에 확정 영상이 없다고 정확히 짚었고 생성·프롬프트도 없었다. 다만 순서를 제안하지 않고 세 작업의 질문 7개를 한 번에 물었다. "세 프롬프트를 검사까지 돌려서 보여 드리겠습니다"라고 한 번에 쓸 계획이었다. OK 카드 3장을 열었고 `cd /절대경로 && …`를 썼다 |

키트 결함: 작업 여럿을 한 번에 말할 때의 규칙이 없었다(지침 3번은 한 생성의 변경만 다룬다). → must-ask '모든 작업'에 '순서를 제안하고 첫 것만 묻는다'를 추가했다.
총평: 판단은 맞았고 진행 방식이 과했다.
