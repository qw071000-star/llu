# r4-C01 (3턴째 "작품명은 빈 정류장.")

| 턴 | 기대 | 판정 | 근거 |
|---|---|---|---|
| 1 | 정본 비어 있음 -> project-setup, 14개 질문 표 한 번에, 준 정보 채움, 생성·폴더 없음 | PASS | "| 13 | **작품명(가제) — 필수** | 기본값 없음", 실사·3분 채움, [TOOL] 없음 |
| 1 | G4/G8 필요한 것만 | 부분 | project-setup과 함께 production-session SKILL.md도 열었다(읽기 지도상 새 작품은 project-setup뿐) |
| 2 | 작품명 다시 묻고 나머지 진행, decisions/shot-list/asset-registry 초안 | PASS | "작품명은 필수 칸이라 기본값으로 채우지 않았습니다", 날짜+기본값 표기, CH-001/002 LC-001 ID |
| 2 | 틀 예시 줄 삭제, ok-cuts 빈 목록 | FAIL | "ok-cuts.md: 예시 줄을 지우진 않고 빈 상태로 둡니다(첫 승인 때 지움)" (project-setup §2와 반대) |
| 2 | G3 같은 질문 반복 | 부분 | 1턴에서 물은 시나리오를 2턴, 3턴 끝에서 또 물음 |
| 3 | 폴더 생성(11번 동의=승인), "이 프로젝트" 세 줄, 다음 순서 | PASS | create_project/create_folder 5건, instructions.md 세 줄 diff, 인물 시트->장소->소품->컷 카드 |
| 3 | 틀의 예시/빈칸 정리 | FAIL | ok-cuts.md 예시 행·예시 카드 그대로, decisions.md:23 `[예: 색감…]`, 정본 우선순위 줄의 `[다르게 정하면 여기 고친다]` 남음 |

턴 판정: PASS 1 / 부분 2 / FAIL 0 (턴 3은 핵심 충족, 예시 정리 미흡이라 부분. 턴 2도 같은 이유 부분)

검사기: 프롬프트 없음.

추가 발견: asset-registry에 `PR-001 (소품 미정)`, `ST-001 (해당 없음)` 자리표시자를 남김(PR는 ID만 매기라는 §2와 어긋남은 아님). CH-001 틀의 `[ ]` 칸은 틀 구조라 허용.

키트 결함
- project-setup/SKILL.md §2 "예시 줄·예시 카드는 지운다"가 한 줄 뒤쪽 불릿에 묻혀 있어 ok-cuts 정리를 건너뜀. 제안: "ok-cuts.md 예시 행·카드 삭제, decisions §3의 `[예:…]`·정본 우선순위 대괄호 줄 정리"를 파일별 체크리스트로.
- 같은 질문(시나리오) 반복 금지가 setup에 없음. 제안: "시나리오 질문은 1턴 한 번만".
- 지침 "대화를 시작할 때 3. production-session" 과 읽기 지도("새 작품: project-setup")가 겹쳐 불필요하게 연다. 제안: 새 작품은 project-setup만이라고 한 줄.

총평: 질문 단계와 폴더 생성은 정확, 정본 틀 청소를 빠뜨림.
