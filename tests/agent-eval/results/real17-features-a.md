## 키트 결함 (아직 열려 있는 것)

1. `kit/skills/production-session/SKILL.md:28` + `kit/instructions.md:38` (기능 44): "On start: read decisions, shot-list, asset-registry"가 총괄 세션 시작에만 걸려 있고, "대장 정리" 같은 한 파일짜리 요청에서는 건너뜀. 수정: instructions.md:38을 `1. Read decisions.md, shot-list.md, asset-registry.md (all three, even when the request names one file, e.g. "대장 정리"). Missing or empty → new work.`로 파일 이름을 직접 적기.
2. `kit/context/tasks.md:8` (§1 "Go straight on")와 `:32` (기능 2): 15번 조건("empty `확정 영상` → 13/14")이 표 셀 괄호에만 있어서 첫 줄 번호를 정할 때(정본 읽기 전) 놓침(C59). 수정: §1에 "Before writing the first line for 15, check the cut's `확정 영상` in shot-list.md; empty → 13 (14 if it is a 배경 cut)" 한 줄 추가(여러 작업 중 첫 작업 번호에도 적용).
3. `kit/skills/shot-design/SKILL.md:51-52` (기능 30): 템플릿의 `shot-list.md로 옮길 줄`이 `[N]-1` 한 줄 예시뿐이라 C56이 "추가하는 줄만"으로 줄였고, 시간 칸이 `[초]`라 컷 목록의 시간 칸(타임라인 `0:40`)과 뜻이 달라 보임. 수정: 예시를 `[N]-1`, `[N]-2`, `…` 여러 줄로 쓰고 "every cut of the scene, including kept and shifted cuts, even when only one cut is added"를 한 줄 덧붙이고 시간 칸을 `[시:분 시작]`으로.
4. `kit/skills/video-prompt/SKILL.md:83` (기능 19): 사건 수 예시(`turns, walks over, takes her hand = 3`)가 한 사람 것만 세는 걸로 읽혀 C47이 상대 인물의 시선 내림·손가락 움직임을 빼먹음. 수정: "Count every character's visible verbs together (the other person lowering eyes or tightening fingers counts too)"와 두 사람 예시 하나 추가.
5. `kit/instructions.md:12` (기능 1): 규칙은 이미 있는데 `Now …` 같은 영어 접속 줄이 C08·C68의 카드 형식을 읽은 직후에 또 나옴. 수정: 같은 줄에 금지 예와 대체 예를 적기 — `never "Now…", "Let me…", "Check passed"; write e.g. "카드 형식을 확인했습니다."`.
