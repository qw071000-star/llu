3. 짚어야 할 충돌을 놓쳤나: C20 t1에서 형광등 켜기 vs 해가 유일한 key(LIGHT LOCK) 충돌을 1턴에 말하지 않았다(2턴에 새 LIGHT LOCK 초안을 보임). 정본과 다른 요청(C07 유형), 승인 컷 대체, 반대 카메라 좌우, 사건 수 초과, 가리키는 이미지 없음, 작업 여럿은 모두 정상.
