# 설치 프롬프트 시험 (`guides/설치-프롬프트.md` 1번, Claude Code, Sonnet)

| 시험 | 결과 |
|---|---|
| 1차 로컬 경로 | 설치 PASS. 그러나 `.claude/instructions.md`를 승인 없이 고칠 수 없어 This project 칸을 못 채움 → `install.sh --title/--higgsfield/--canon` 추가, 프롬프트가 설치 전에 세 칸을 묻게 바꿈 |
| 1차 GitHub 주소 | `main`에 키트가 없어(PR 머지 전) 설치하지 않고 멈춤, 폴더 변경 없음(맞는 동작) → 프롬프트에 `branch:` 줄 추가 |
| 2차 로컬 경로 | PASS: 추가·교체·유지 목록 + 세 칸 질문 + "설치할까요?" → 명령 1번 → 작품명·정본 위치 채움, Higgsfield는 비어 있다고 안내 |
| 2차 GitHub 주소(브랜치 지정) | PASS: 같은 흐름, 스킬 9개·정본 틀 4개 |
| 설치된 폴더에서 "오늘 뭐 하면 돼?" | 정본이 비어 있어 1번 새 작품 시작을 제안. 폴더를 믿기 전에는 settings.json 허용이 무시된다는 경고가 나옴(안내 5번 단계가 필요한 이유) |

자동 점검: 설치 8개 포함 798/798.
