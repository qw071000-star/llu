# 에셋·폴더 대장 — 「빈 정류장」

> 고정 설명문은 프롬프트에 글자 그대로 붙인다. 바꿔야 하면 새 버전(v2)을 만들고, 옛 것은 폐기 목록으로 옮긴다.
> 확정 이미지의 정본은 Higgsfield 저장본이다. job ID로 직접 열어 확인한다.
> 확정 에셋을 만든 프롬프트와 설정은 OK 대장(`ok-cuts.md`)의 에셋 ID 카드에 있다.
