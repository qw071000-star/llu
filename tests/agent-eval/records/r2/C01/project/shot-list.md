> **컷 상태:** `대기` → `진행` → `검토` → `승인`. 중간에 `보류`가 될 수 있다.
> 상태의 정본은 이 표다. Higgsfield 컷 폴더 이름(`3-1 [승인]`)은 같은 상태를 보여 주는 사본이다.
> 컷 번호는 장면-컷(`3-1`)이다. 확정 job의 설정과 프롬프트는 OK 대장(`ok-cuts.md`)에 있다.
