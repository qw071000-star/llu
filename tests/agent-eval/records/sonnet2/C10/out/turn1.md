[카메라]
1. 위치·렌즈: 제안 — 시작 이미지 그대로. 길 가까운 쪽 가장자리, 시간표 맞은편, 서서 눈높이, 북쪽을 봄, 완전 고정. 렌즈는 50mm = 대각 약 47° (이유: 시작 이미지가 50mm로 승인됨). 관찰 결과: 손녀와 시간표가 화면 오른쪽 절반 / 쉘터 끝이 왼쪽 가장자리 / 벤치는 프레임 밖. 심도는 손녀 선명, 먼 논은 약간 부드럽게.

[인물]
2. 끝 자세와 동선: 제안 — 제자리에서 몸만 돌립니다. 마지막 프레임은 시간표에서 반 걸음 떨어져, 몸이 화면 왼쪽(벤치 쪽)을 향한 4분의 3 정면이고 손은 내립니다. 길로 나가지 않고 걸음은 없습니다. (이유: 사건을 줄이려고. 3-4에는 손녀가 나오지 않아 끝 자세가 자유로움)
3. 돌아서는 방식: 제안 — 3-1 영상(OK, "손녀 돌아서는 속도 딱 좋다")에서 모션만 가져옵니다. 눈 → 머리 → 어깨 순서, 약 1.5초, 느리고 고르게. 바꾸는 것: 구간 0:03–0:05 → 0:04–0:06, 대사와 걸음 삭제, 방향은 벤치 쪽(화면 왼쪽)으로 같음. 함께 가져오는 위험: 눈물 = 실패, 장난스러운 태도 = 실패. 괜찮은지요?
4. 시선: 제안 — 0:00–0:04 시간표의 시간 줄, 0:04부터 눈이 먼저 시간표에서 떨어져 화면 왼쪽 프레임 밖(벤치 쪽)을 봄. 카메라는 보지 않음. (이유: 지난 3-2 시도가 시선이 카메라를 봐서 폐기됨) 반응하지 않을 사람은 이 샷에 없음.

[타이밍]
5. 구간: 제안 — 0:00–0:04 시간표 위의 손이 시간 줄을 한 번 따라 내려가 멈춤(= "한 번 더 본다"). 0:04–0:06 돌아섬. 0:06–0:08 정지, 마지막 프레임. 사건 2개. 이음새: 앞에서 이어받는 것은 시작 이미지가 전부이고, 다음 3-4 첫 프레임과 맞출 것은 가방 닫힘(이음새 표)뿐입니다.
