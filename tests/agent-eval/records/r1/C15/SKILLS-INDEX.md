# 이 환경에서 쓸 수 있는 스킬 (이름과 설명만 항상 보인다)

- **acting**: AI 영상에서 인물 연기를 쓸 때 쓴다. 15블록의 CHARACTER_ACTING을 채울 때, 인물 마스터 프로필이나 목소리 문장을 만들 때, 연기가 과하거나 죽었을 때 쓴다. 증상은 감정 과잉, 무표정, 휙 도는 동작, 말하지 않을 인물의 입 움직임, 죽은 눈, 배경 인물이 얼어붙음 같은 것이다. 다루는 것: 목표와 행동, 손의 일, 눈의 삶, 상태 쓰기, 레지스터, 검증된 문장.
- **higgsfield-generation**: Higgsfield로 이미지·영상을 생성하거나 결과물을 정리할 때 쓴다. Seedance, Kling, GPT Image, Nano Banana, Seedream 등 모델에 쓴다. 다루는 것: 생성 전 점검과 프롬프트 자동 검사, 저장 프로젝트·폴더 확인과 폴더 구성 제안, 요청 후 기다리지 않고 턴 끝내기, 결과물 승인(OK)·거절·보류 표시(폴더 이동, 컷 폴더 이름), OK 대장에 프롬프트까지 기록, 결과 확인, 해상도 단계, 크레딧 절약.
- **image-prompt**: AI 이미지 생성·편집 프롬프트를 쓰거나 고칠 때 쓴다. GPT Image, Nano Banana, Seedream에 해당한다. 대상은 에셋 제작과 영상 시작용 퍼스트 프레임이다. 에셋은 장소, 소품, 인물+의상 시트, 그림체 이미지다. 공통 규칙은 이 파일에 있다. 신규와 편집의 구분, 참조 권한, 편집 문법, 크롭이다. 종류별 규칙과 빈 틀은 따로 있는 파일을 그 종류일 때만 읽는다.
- **production-session**: AI 영상 제작 프로젝트에서 총괄 세션과 컷 세션을 운영한다. 다음 경우에 쓴다. 새 대화를 시작할 때, 컷 카드를 만들거나 받을 때, 핸드오프를 쓰거나 반영할 때, 정본(decisions.md, asset-registry.md, shot-list.md, ok-cuts.md)을 고칠 때, 대화가 길어져 새 대화로 넘길 때. 사용자가 다른 OK 컷을 기준으로 말할 때("3-1처럼 3-2", "3-1의 색감으로", "2-1 표정 유지").
- **project-setup**: 새 AI 이미지·영상 작품을 시작할 때 쓴다. "새 작품 시작", "프로젝트 세팅", "처음부터 준비" 같은 요청이나, 정본(decisions.md, asset-registry.md, shot-list.md, ok-cuts.md)이 비어 있을 때 해당한다. 하는 일은 넷이다. 시작 전 질문을 한 번에 묻는다. 확정 사항·에셋 대장·컷 목록 초안을 만든다. Higgsfield 프로젝트와 폴더 구성을 정한다. 다음 순서를 안내한다.
- **video-prompt**: AI 영상 생성 프롬프트를 쓰거나 고칠 때 쓴다. Seedance, Kling, image-to-video, 시작·끝 프레임 영상에 해당한다. 공통 규칙은 이 파일에 있다. 샷 설계, 사건 수, 카메라, 좌표, 모델 메모, 점검이다. 형식별 파일을 그 형식일 때만 읽는다. 실사·인물 컷은 15블록, 배경·풍경·그림체는 4문단이다. 결과가 틀렸을 때는 증상별 수정 파일을 읽는다.
