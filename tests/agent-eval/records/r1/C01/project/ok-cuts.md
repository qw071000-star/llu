# OK 대장 — 「빈 정류장」(가제)

> 사용자가 OK(승인)한 결과물만 둔다. 승인한 그 자리에서 쓴다.
> 프롬프트는 생성에 보낸 글자 그대로 둔다. 기억으로 다시 쓰거나 다듬지 않는다.
> 목록은 기준이 필요할 때 읽는다. 카드는 그 번호를 가져다 쓸 때 그 카드 하나만 연다.
> 같은 번호·종류의 새 OK가 생기면 옛 카드는 로그로 옮기고 목록 줄을 바꾼다.

## 목록

| 번호 | 종류 | job | 모델 · 설정 | 승인일 | OK 이유 (가져다 쓸 만한 것) | 한계 |
|---|---|---|---|---|---|---|
| 3-1 | 영상 | `[ ]` | [모델 · 해상도 · 길이 · 비율 · 소리] | | [예: 고개 돌리는 속도, 할아버지 표정, 색감] | |

- **번호:** 컷은 장면-컷(`3-1`), 에셋은 에셋 ID(`CH-001`, `LC-001-V2`).
- **종류:** 시작 이미지 · 끝 이미지 · 영상 · 인물 · 장소 · 소품 · 그림체.

## 카드

### 3-1 영상

- job: `[ ]` · 승인: [날짜] · 저장: [컷 폴더] / 승인
- 모델 · 설정: [모델] · [해상도] · [길이] · [화면비] · 소리 [켬/끔] · 시드 [있으면]
- 시작 이미지: [job] · 끝 이미지: [job / 없음]
- 참조(붙인 순서): 1 [ID — 역할] · 2 [ID — 역할] · …
- 가져온 OK: [다른 카드에서 가져온 것 — 없으면 "없음"]
- OK 이유: [사용자가 좋다고 한 것, 사용자 말 그대로]
- 한계: [알고 넘어간 문제]
- 프롬프트(보낸 그대로):

```text
[ ]
```
