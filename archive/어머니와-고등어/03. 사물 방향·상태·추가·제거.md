# 03. 사물 방향·상태·추가·제거
 
## 1. 이 가이드가 해결하는 작업
 
같은 장소 사진에서 사물의 방향이나 작동 상태만 바꾸거나, 기존 앵커에 대상을 추가하거나, 대상 하나를 제거한다.
 
근거: 원문 6, 12, 17, 18.
 
## 2. 사용 조건과 사용하면 안 되는 경우
 
사용한다:
 
- 모니터를 제자리에서 세로로 회전한다.
- 화면이나 장치를 켜고 끈다.
- 기존 좌석에 인원을 추가한다.
- 침대 위 소품 하나를 제거한다.
사용하지 않는다:
 
- 사물을 A 위치에서 B 위치로 옮긴다.
- 사물을 다른 디자인으로 일대일 교체한다.
- 일반 소품의 재질·손잡이만 바꾼다.
마지막 세 작업은 직접 원문 두 개가 없어 이 가이드에서 다루지 않는다.
 
## 3. 필요한 입력 정보
 
- 대상의 고유 식별자와 화면상 위치
- 현재 위치·방향·상태
- 변경할 속성 하나
- 그대로 둘 속성
- 대상의 앵커 또는 접촉면
- 주변 빛·그림자에 미칠 허용 영향
## 4. 먼저 잠글 항목
 
- 카메라와 장소 구조
- 대상의 위치·크기·높이
- 변경하지 않는 대상 속성
- 주변 사물과 접촉면
- 광원·노출·그림자
방향을 바꾸면 위치를 잠그고, 상태를 바꾸면 형태와 방향을 잠근다.
 
## 5. 변경할 항목의 작성 순서
 
1. 대상을 위치와 함께 식별한다.
2. 작업을 `ROTATE`, `CHANGE STATE`, `ADD`, `REMOVE` 중 하나로 고른다.
3. 바뀌는 속성을 하나의 동사로 쓴다.
4. 바뀌지 않는 속성을 바로 이어서 적는다.
5. 주변 빛과 접촉면 처리를 적는다.
6. 장소 전체 보존 목록으로 닫는다.
## 6. 영어 프롬프트 공식
 
### 방향
 
```text
Keep [object] in the exact same position, at the same height and on the same mount. Rotate only [named part] [degrees/direction] so that it faces [target]. Preserve its design, scale and support.
```
 
### 상태
 
```text
This is the same object in the same position with one state change only: [old state] becomes [new state]. Preserve its shape, dimensions, material, orientation and surroundings.
```
 
### 추가
 
```text
Add [subject/object] only at [existing anchor], matching its existing scale, perspective, contact and light. Do not alter the anchor or surrounding structure.
```
 
### 제거
 
```text
Remove [object] from [location]. Continue [revealed surface] naturally through the vacated area. Preserve everything else exactly.
```
 
## 7. 완성 템플릿
 
```text
Edit <<<image_1>>> WITHOUT reframing: the camera, framing, room geometry and all untargeted objects are LOCKED — this is the same photograph with one change only.
 
CHANGE — [OBJECT AT LOCATION]:
[Rotate / switch / add / remove] [exact instruction].
Keep [position, scale, orientation or design attributes that must not change].
[Describe contact surface, revealed area or permitted local light behavior].
 
PRESERVE EXACTLY:
- Camera position, angle, lens, framing and perspective
- Architecture and all unnamed objects
- [Target attributes not being changed]
- Existing light, shadows, exposure and colour grade
 
ONLY CHANGE: [single closed change]. Everything else remains identical.
```
 
### 템플릿 변수
 
- `[OBJECT AT LOCATION]`: 다른 대상과 혼동되지 않는 사물명과 위치
- `[Rotate / switch / add / remove]`: 네 작업 중 하나
- `[exact instruction]`: 각도·작동 상태·앵커·제거 범위를 포함한 지시
- `[Target attributes not being changed]`: 위치·크기·형태·재료 중 보존할 속성
- `[single closed change]`: 허용된 단일 변경의 짧은 재진술
## 8. 실제 원문 핵심 발췌
 
원문 6 — 위치와 마운트를 유지한 채 모니터만 회전한다.
 
```text
the monitor ... is rotated 90 degrees on its mount
...
Its position above the desk and its arm stay exactly where they are.
```
 
원문 12 — 기존 좌석을 앵커로 관객을 추가한다.
 
```text
The figures sit IN the existing seats, at the scale those seats already have in the reference.
```
 
원문 17 — 한 대상만 제거하는 최소 문장이다.
 
```text
Remove the suitcase on the bed. Preserve everything else exactly.
```
 
원문 18 — 같은 그래픽을 유지하고 상태만 바꾼다.
 
```text
the same graphics, the same shapes, the same positions, simply re-coloured red
```
 
## 9. 발췌에서 확인되는 공통 문법
 
- 대상은 `nearest monitor`, `right-hand column`처럼 위치까지 묶어 식별한다. (원문 6, 18)
- 방향 변경은 마운트와 위치를 고정한다. (원문 6)
- 상태 변경은 형태·배치·그래픽 구조를 고정한다. (원문 6, 18)
- 추가는 새 위치를 발명하지 않고 기존 앵커를 사용한다. (원문 12)
- 단순 제거는 짧게 쓰되 제거 대상과 보존 범위가 명백해야 한다. (원문 17)
## 10. 자주 발생하는 실패와 교정 문장
 
### 회전하면서 대상이 이동함
 
```text
Rotate it in place around its existing mount; do not translate, raise, lower or resize it.
```
 
### 전원을 켰더니 디자인이 달라짐
 
```text
The same device, bezel, mount, dimensions and orientation remain unchanged; only its powered state changes.
```
 
### 추가 대상이 기존 구조를 가림
 
```text
Place the new subject within the existing [anchor], at its established scale, without moving or covering adjacent landmarks.
```
 
### 제거 자리에 잔상이 남음
 
```text
The object is completely gone; the underlying surface continues naturally with no residual shadow, indentation, fragment or duplicate.
```
 
## 11. AI 내부 작성 절차
 
1. 바꿀 속성을 하나 고른다.
2. 그 속성을 제외한 대상 속성을 보존 목록으로 만든다.
3. 대상의 위치 표현이 유일한지 확인한다.
4. 추가라면 기존 앵커, 제거라면 드러날 표면을 지정한다.
5. 카메라나 장소 변경이 섞이면 `02` 또는 `06`으로 분리한다.
## 12. 생성 전 점검표
 
- [ ] 대상이 하나로 식별되는가
- [ ] 방향·상태·추가·제거 중 하나인가
- [ ] 위치·크기·마운트 잠금이 필요한 만큼 있는가
- [ ] 접촉면이나 제거 후 표면이 정의됐는가
- [ ] 주변 조명 변화의 허용 범위가 명확한가
- [ ] 근거 없는 위치 이동·교체 지시가 없는가
## 13. AI 최종 출력 규칙
 
- 완성된 영어 프롬프트만 출력한다.
- 단일 제거가 명백하면 한두 문장으로 끝낸다.
- 복합 작업이면 `CHANGE / PRESERVE / ONLY CHANGE` 구조를 사용한다.
- 위치 이동·교체를 이 가이드의 규칙으로 임의 확장하지 않는다.
