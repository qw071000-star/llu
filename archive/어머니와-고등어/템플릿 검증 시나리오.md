# 템플릿 검증 시나리오
 
각 가이드의 템플릿을 서로 다른 두 상황에 대입해 필수 입력과 모드 충돌을 확인한 기록이다. 아래 문장은 완성 프롬프트가 아니라 템플릿 검증용 핵심 치환값이다.
 
## 판정 기준
 
- 모든 필수 변수를 실제 값으로 치환할 수 있어야 한다.
- 카메라 고정 작업에는 `WITHOUT reframing`이 있어야 한다.
- 새 시점 작업에는 `WITHOUT reframing`이 없어야 한다.
- 변경 항목과 보존 항목이 서로 충돌하지 않아야 한다.
- 근거 원문에서 확인되지 않은 작업을 추가하지 않아야 한다.
## 01. 레퍼런스 권한 분리
 
### 시나리오 A — 구도와 화면 참조 분리
 
- 기준: 이미지 1이 카메라·방·기기 배치를 통제
- 보조: 이미지 2가 모니터 화면 내용만 통제
- 통과 조건: 이미지 2의 카메라·책상·빛을 가져오지 않음
### 시나리오 B — 레이아웃과 재료 참조 분리
 
- 기준: 이미지 1이 문·창·침대·수납장 배치만 통제
- 보조: 이미지 2가 연구 시설의 표면과 창호만 통제
- 통과 조건: 이미지 1의 무대·조명, 이미지 2의 구도를 복사하지 않음
## 02. 고정 구도 부분 수정
 
### 시나리오 A — 유리 너머 방 교체
 
- 변경: 기존 휴게 공간을 서버룸으로 교체
- 보존: 카메라·유리 프레임·현재 방의 가구·노출
- 통과 조건: `CHANGE / PRESERVE EXACTLY / ONLY CHANGE` 목록 일치
### 시나리오 B — 좌석 점유 상태 변경
 
- 변경: 기존 좌석에 관객 실루엣 추가
- 보존: 무대·세트·프로시니엄·조명·카메라
- 통과 조건: 관객이 좌석 축척과 원근을 따름
## 03. 사물 방향·상태·추가·제거
 
### 시나리오 A — 모니터 제자리 회전
 
- 변경: 오른쪽 모니터를 기존 암에서 90도 회전
- 보존: 암 위치·화면 높이·책상·주변 모니터
- 통과 조건: 이동·리사이즈 없이 회전만 발생
### 시나리오 B — 침대 위 여행가방 제거
 
- 변경: 여행가방 제거
- 보존: 침구·주름·침대 위치·방 전체
- 통과 조건: 제거 자리의 침구가 자연스럽게 이어짐
## 04. 화면 UI 상태 수정
 
### 시나리오 A — 오른쪽 컬럼 경고
 
- 변경: 오른쪽 컬럼만 적색 경고와 정확한 문구 표시
- 보존: 왼쪽 컬럼·UI 좌표·패널·책상·노출
- 통과 조건: 왼쪽에는 적색 요소가 없고 방에 광 누출이 없음
### 시나리오 B — 터미널 화면 켜기
 
- 변경: 지정한 두 화면만 흰 모노스페이스 터미널로 켬
- 보존: 기기 디자인·방향·방 조명
- 통과 조건: 아이콘·컬러 그래픽·블룸이 없음
## 05. 카메라 역방향 전환
 
### 시나리오 A — 반대편 끝에서 되돌아보기
 
- 방식: 카메라를 복도 먼 끝으로 이동
- 보존: 중앙축·폭·높이·문 간격·재료
- 통과 조건: 원래 카메라 방향을 향한 새 원근
### 시나리오 B — 같은 지점에서 180도 회전
 
- 방식: 카메라 위치 유지, 시선만 반대 축으로 회전
- 보존: 높이·중심축·반복 리듬
- 통과 조건: 반대편 끝 이동 문구가 섞이지 않음
## 06. 같은 장소의 새 시점
 
### 시나리오 A — 워크스테이션 클로즈업
 
- 카메라: 원래 시선축을 따라 같은 쪽에서 전진
- 주체: 책상·모니터·키보드·구
- 제외: 문과 암체어
- 통과 조건: 새 프레임이지만 동일 워크스테이션 디자인 유지
### 시나리오 B — 태블릿 탑뷰
 
- 카메라: 패널 표면에 수직
- 주체: 태블릿과 좁은 책상 테두리
- 제외: 방·의자·소파
- 통과 조건: 사선 시점과 잠금 편집 문구가 없음
## 07. 같은 건물의 새 공간
 
### 시나리오 A — 입구 홀
 
- 공통: 회색 석재·스모크 유리·가느다란 금속 프레임·간접광
- 새 기능: 리셉션과 출입 동선
- 통과 조건: 기존 실험실 가구를 복사하지 않음
### 시나리오 B — 계단실
 
- 공통: 동일 재료·문·조명 체계
- 새 기능: 하부 연구 층과 지상층 연결
- 통과 조건: 계단의 높이와 순환이 공간의 주체가 됨
## 08. 레이아웃 고정 변환
 
### 시나리오 A — 카메라까지 고정한 침실 변환
 
- 보존: 왼쪽 문·중앙 창·창 아래 침대·오른쪽 수납장·카메라
- 변경: 세트 맥락·재료·광원
- 통과 조건: 앵커의 위치·크기·각도 불변
### 시나리오 B — 레이아웃만 사용한 새 침실
 
- 보존: 앵커의 상대 위치
- 변경: 카메라·재료·조명·현실 공간
- 통과 조건: `WITHOUT reframing`이 없음
## 09. 세트에서 실제 공간으로
 
### 시나리오 A — 잠금 변환
 
- 보존: 무대 위 방의 프레임과 내부 배치
- 제거: 프로시니엄·객석·무대등·무대 바닥
- 구축: 실제 벽·천장·바닥·창밖 도시
- 통과 조건: 화면 가장자리에 세트가 남지 않음
### 시나리오 B — 레이아웃 재생성
 
- 보존: 문·창·침대·수납장 관계
- 새 카메라: 실제 방 모서리의 3/4 시점
- 통과 조건: 무대 시점을 복사하지 않고 현실 축척 유지
## 10. 시대·재료·디자인 교체
 
### 시나리오 A — 스튜디오 외관을 연구 시설로
 
- 보존: 건물 볼륨·도로·식재·야간 구도
- 변경: 표지·파사드·경비실·차량·건물 조명
- 통과 조건: 원래 시대 차량·전구·재료가 남지 않음
### 시나리오 B — 침실을 연구 시설 내부로
 
- 보존: 침대·수납장·러그·가구 위치
- 변경: 영구 표면·문·창 영역·조명
- 통과 조건: 보존 가구와 새 시설 표면이 구분됨
## 11. 소품 독립 에셋 파생
 
### 시나리오 A — 프롬프터 박스 맥락형 클로즈업
 
- 카메라: 무대 바닥의 낮은 3/4 시점
- 보존: 골진 목재 돔·벗겨진 바니시·황동 테두리
- 맥락: 무대 판재와 어두운 객석
- 통과 조건: 새 소품 디자인을 발명하지 않음
### 시나리오 B — 태블릿 판독용 근접판
 
- 카메라: 정면 탑뷰 또는 완만한 사선 중 하나
- 보존: 큰 패널·얇은 베젤·책상 접촉 관계
- 제외: 방과 무관한 가구
- 통과 조건: 선택하지 않은 카메라 유형이 섞이지 않음
## 12. 다단계 제작 계보
 
### 시나리오 A — 연구 시설
 
- 계보: 실험실 MASTER → 관찰실 구조판 → 모니터 STATE → 워크스테이션 VIEW → 태블릿 PROP → 경고 UI STATE
- 통과 조건: 구조·카메라·화면 상태가 각각 별도 단계
### 시나리오 B — 극장과 침실
 
- 계보: 극장 MASTER → 관객 STATE → 프롬프터 PROP → 실제 침실 변환 → 여행가방 FIX
- 통과 조건: 각 자식판에 부모 하나와 변경 영역 하나가 있음
