# 설치 프롬프트 — 새 작품에 키트를 바로 넣기

> **붙여 넣을 글만 필요하면 `붙여넣기/1-설치-ClaudeCode.txt`, `붙여넣기/2-설치확인-Claude앱.txt`를 연다.** 이 문서는 설명이다.
> 다른 사람도 이 문서 하나로 설치할 수 있게 만들었다. 자세한 설명은 `guides/세팅.md`에 있다.
> 키트는 공개 리포 `qw071000-star/lucian-Claude-Higgsfield-Cinematic-kit`에 있다. 인터넷이 막힌 곳이면 리포를 zip으로 받아 압축을 푼 폴더 경로를 프롬프트에 적는다.

## 1. Claude Code — 프롬프트 하나로 설치

1. 작품 폴더를 만들고 그 폴더에서 `claude`를 연다(빈 폴더도, 이미 쓰던 작품 폴더도 된다). Mac·Linux 기준이다. Windows는 WSL이나 Git Bash에서 연다. `git`과 `python3`가 있어야 한다.
2. 아래 상자 안의 글을 통째로 붙여 넣는다. 키트를 zip으로 받았으면 `Kit source:` 줄의 주소 대신 압축을 푼 폴더 경로를 적는다.
3. Claude가 무엇을 추가·교체·유지할지 보여 주고, 세 가지(작품명, Higgsfield 프로젝트, 정본 위치)를 물은 뒤 "설치할까요?"라고 묻는다. 세 가지를 답하면서 "응"이라고 한다. 모르는 것은 "몰라"라고 하면 비워 둔다.
4. 설치 명령 하나만 승인하면 된다.
5. `claude`를 닫았다가 다시 열고, "이 폴더를 믿는가" 창을 승인한다.

키트가 새 버전으로 바뀌었을 때도 같은 프롬프트를 쓴다. 정본(`project/`)과 채워 둔 "This project" 칸은 그대로 남는다.

```text
Install (or update) the Higgsfield Cinematic Kit (AI image/video production with Claude) into this folder. Answer me in Korean.

Kit source: https://github.com/qw071000-star/lucian-Claude-Higgsfield-Cinematic-kit · branch: main

1. Get the kit outside this folder: if the source is a URL, shallow-clone that branch to ~/.cache/higgsfield-cinematic-kit (if that folder exists, check out that branch there and git pull). If <kit>/kit/install.sh is missing, stop and tell me the branch has no kit. If the source is a local path, use it as is. If cloning fails (no network or no access), stop and tell me in one line to get access or give a local path.
2. Before changing anything, look at this folder (CLAUDE.md, .claude/, project/) and show me one short list: what will be added, what will be replaced (.claude/instructions.md, .claude/context/, .claude/skills/, .claude/settings.json) and what will be kept (project/ canon, CLAUDE.md, the filled "This project" section). In the same message ask for the three "This project" fields (skip any already filled): 작품명, Higgsfield project (이름과 ID), 정본 위치 (proposal: repo `project/`); "몰라" leaves a field empty. End with "설치할까요?" and wait.
3. After I agree, run in one Bash call: bash <kit>/kit/install.sh . plus --title "<작품명>", --higgsfield "<이름> (<ID>)", --canon "<정본 위치>" only for the fields I answered (the script fills them; do not edit .claude/ files yourself).
4. Show the script's result lines as they are. If any line starts with "확인", explain it in one line; if "채움" lists empty fields, say they can be filled later in .claude/instructions.md.
5. Finish with these steps for me, one line each: connect the Higgsfield MCP in Claude Code if it is not connected; close and reopen claude in this folder and approve "trust this folder"; first message "새 작품 시작할게." (empty canon) or "총괄 세션이야. 오늘 뭐 하면 돼?"; for per-scene and per-cut sessions see guides/세션-시작.md in the kit.

Never generate images or videos. Do not change files outside this folder except the kit cache. Do not commit or push.
```

## 2. Claude 앱 (claude.ai) — 프롬프트로는 설치되지 않는다

앱은 스킬 업로드와 지침 칸을 사람이 직접 넣어야 한다. 순서만 따라 하면 10분이면 된다. 설정에서 코드 실행(파일 만들기)이 켜져 있어야 스킬을 올릴 수 있다.

1. 설정 → 스킬 → "Upload a skill"로 `kit/dist/`의 zip 7개를 하나씩 올린다: `project-setup`, `production-session`, `higgsfield-generation`, `image-prompt`, `video-prompt`, `acting`, `shot-design`. (`assembly`, `color-continuity`는 앱에서 돌지 않는다.) 스킬은 계정마다 올린다.
2. 설정 → 커넥터에서 Higgsfield를 연결한다. 정본을 Claude Doc으로 쓰면 Claude Docs도 연결한다.
3. 새 프로젝트를 만들고, 지침 칸에 `kit/dist/project-instructions.md`를 통째로 붙인다.
4. 프로젝트 지식에는 시나리오·콘티만 넣는다. `guides/`, `reference/`, `tests/`는 넣지 않는다.
5. 그 프로젝트의 새 대화에 아래 글을 붙여 설치가 됐는지 확인한다.

```text
키트 설치 확인만 해 줘. 생성은 하지 마.
1. 올라온 스킬 중 project-setup, production-session, higgsfield-generation, image-prompt, video-prompt, acting, shot-design이 보이는지 하나씩 적어 줘.
2. 지침의 "This project" 칸에서 비어 있는 줄을 알려 주고, 채울 값을 나에게 한 번에 물어봐. 답하면 고친 줄만 보여 줘(지침 칸은 내가 직접 고친다).
3. Higgsfield 커넥터가 연결돼 있는지 확인해 줘(목록 조회만).
4. 정본이 어디 있는지, 비어 있으면 "새 작품"으로 시작하면 된다고 알려 줘.
```

## 3. 다른 사람에게 줄 때

- 이 문서 링크 하나만 주면 된다. Claude Code 사용자는 1번, 앱 사용자는 2번을 본다.
- 팀원마다 각자 해야 하는 것: 스킬 업로드(앱), Higgsfield 커넥터 로그인, Claude Code의 "이 폴더를 믿는가" 승인.
- 정본은 팀에 하나만 둔다. 두 번째 사람부터는 새 정본을 만들지 말고 같은 리포나 같은 Claude Doc을 쓴다.
- 설치 뒤 처음 쓰기 전에 `guides/알아둘-것.md`를 한 번 본다.
- 씬·컷마다 새 대화를 열 때 할 말은 `guides/세션-시작.md`에 있다.
