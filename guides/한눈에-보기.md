# 한눈에 보기 — AI 실사 영상 제작 키트

> Claude에게 말로 시키면, Claude가 알맞은 스킬을 골라 프롬프트를 쓰고 Higgsfield로 만든다.
> 처음이면 이 한 장만 보면 된다. 더 자세한 것은 맨 아래에 있다.

## 1. 무엇이 있나

**스킬 (키트에 들어 있음)**

| 스킬 | 한 줄 설명 |
|---|---|
| `project-setup` | 새 작품 시작. 질문 한 번으로 기본 설정과 폴더를 만든다 |
| `shot-design` | 대본 한 장면을 컷으로 나눈다(어디서 찍을지, 180도 선) |
| `production-session` | 대화 시작, 컷 카드, 핸드오프, "3-1처럼" 재사용 |
| `image-prompt` | 이미지 프롬프트: 인물 시트, 장소, 소품, 그림체, 퍼스트 프레임 |
| `video-prompt` | 영상 프롬프트: 실사 15블록, 배경 4문단, 결과 고치기, 1080p |
| `acting` | 인물 연기(표정·손·시선) |
| `higgsfield-generation` | 실제 생성, 결과 확인, 승인(OK)·거절, 크레딧 |
| `assembly` | 만든 영상 다루기: 마지막 프레임 뽑기, 이어 붙이기, 러프컷 (Claude Code 전용) |

**커넥터**

| 커넥터 | 하는 일 |
|---|---|
| Higgsfield | 이미지·영상 생성과 저장 |
| Claude Docs / Google Drive / Notion | 정본(확정 사항·컷 목록)을 팀과 같이 쓰기 |
| ElevenLabs | 대사·효과음을 따로 만들 때 |

**앞으로 만들 수 있는 것 (아직 없음)**: `sound-design`(효과음·대사 큐시트), `color-continuity`(컷 사이 색 맞추기). 필요해지면 만든다.

## 2. 작업 흐름

| 순서 | 단계 | 스킬 |
|---|---|---|
| 1 | 새 작품 시작 | project-setup |
| 2 | 장면을 컷으로 나누기 | shot-design |
| 3 | 에셋 만들기: 인물 → 장소 → 소품 | image-prompt |
| 4 | 컷마다 퍼스트 프레임 | image-prompt |
| 5 | 컷마다 영상 | video-prompt (+ acting) |
| 6 | 만들고, 확인하고, OK | higgsfield-generation |
| 7 | 이어 붙여 보기 | assembly |

대화 시작·컷 카드·핸드오프는 어느 단계에서든 `production-session`이 맡는다.

컷 하나는 늘 이 순서다: **프롬프트를 본다 → "영상으로 만들어" → 결과를 보고 "됐어" → "OK" 또는 "거절"**.

## 3. 이럴 땐 이렇게 말한다

| 하고 싶은 일 | 이렇게 말하면 된다 | 쓰이는 스킬 |
|---|---|---|
| 새 작품 시작 | "새 작품 시작하자. 실사로 3분짜리" | project-setup |
| 장면을 컷으로 나누기 | "이 장면 컷 나눠줘" | shot-design |
| 인물 만들기 | "할아버지 인물 시트 만들어" | image-prompt |
| 인물 고치기 | "옷을 겨울 코트로", "50대처럼" | image-prompt |
| 장소 만들기 | "정류장 만들어", "반대 방향에서 본 것도" | image-prompt |
| 장소 상태 바꾸기 | "형광등 켜진 걸로", "밤으로" | image-prompt |
| 소품 만들기 | "왕진 가방 만들어" | image-prompt |
| 컷 시작 이미지 | "3-4 퍼스트 프레임 만들어" | image-prompt |
| 인물 영상 | "3-2 영상 프롬프트 만들어" | video-prompt + acting |
| 배경 영상 | "1-1 배경 영상 만들어" | video-prompt |
| 앞 컷처럼 | "3-1처럼 3-2 만들어" | production-session + video-prompt |
| 결과가 이상할 때 | "입이 움직여", "너무 빨라", "구름 더 느리게" | video-prompt |
| 실제로 만들기 | "이미지로 만들어", "영상으로 만들어" | higgsfield-generation |
| 결과 확인·승인 | "됐어" → "OK" / "거절" | higgsfield-generation |
| 고해상도 | "1080p로" | video-prompt + higgsfield-generation |
| 다음 컷 시작 이미지로 | "3-1 마지막 프레임 뽑아" | assembly |
| 이어서 보기 | "3장 이어 붙여 봐" | assembly |
| 오늘 할 일 | "오늘 뭐 하면 돼?" | production-session |

스킬 이름은 몰라도 된다. 말만 하면 Claude가 고른다.

## 4. 꼭 기억할 다섯 가지

1. **"이미지로 만들어", "영상으로 만들어"라고 해야 만든다.** 프롬프트를 먼저 보고 나서 말한다. "그대로", "좋아"는 제안을 받아들인다는 뜻이고, 생성 지시가 아니다.
2. **방향은 화면에 보이는 기준이다.** "왼쪽"은 화면에서 보이는 왼쪽이다. 인물 자신의 손이면 "손녀 입장에서 오른손"처럼 말한다.
3. **한 번에 한 가지만 바꾼다.** 여러 개를 말하면 Claude가 순서를 나눠 준다.
4. **확인은 싸게 한다.** 이미지 1k, 영상 480p로 보고, 확정한 뒤에 고해상도로 뽑는다.
5. **같은 실패가 두 번 나면 멈춘다.** Claude가 샷 나누기나 후반 작업 같은 다른 방법을 제안한다.
